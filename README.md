# SmartStay APK Demo

Este directorio contiene el APK de demostración de la aplicación móvil SmartStay.

## Archivo

- `smartstay-demo.apk`

## Descripción

SmartStay es una aplicación móvil orientada a la gestión hotelera y la experiencia del huésped. Esta versión demo presenta la pantalla inicial de la app, basada en el landing page del proyecto.

## Contenido de la demo

La versión actual incluye:

- Pantalla principal de SmartStay.
- Sección de presentación del producto.
- Información de "Quiénes Somos".
- Cards de productos y servicios principales.
- Botón visual de demo.

## Requisitos

- Dispositivo Android o emulador Android.
- Android 11 o superior recomendado.

## Instalación

1. Descargar el archivo `smartstay-demo.apk`.
2. Abrir el APK en un dispositivo Android o emulador.
3. Permitir la instalación si Android solicita autorización.
4. Instalar la aplicación.
5. Abrir SmartStay.

## Observación

Este APK corresponde a una versión de avance académico. Algunas funcionalidades son demostrativas y no están conectadas aún a servicios reales.
